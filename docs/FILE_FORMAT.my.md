# ဖိုင်ပုံစံ လမ်းညွှန် (ဆရာ/ဆရာမများအတွက်)

**အတန်း (row) တစ်ကြောင်း = လေ့ကျင့်ခန်း တစ်ခု** ဖြစ်ပါတယ်။ ဖိုင်တစ်ခု (သို့မဟုတ် Excel sheet တစ်ခု) = **လေ့ကျင့်ခန်းအစု တစ်ခု** ဖြစ်ပါတယ်။

## ၁။ အမြန်ဆုံး စတင်နည်း

app ထဲက **Guide > Download template (.csv)** ကို နှိပ်ပြီး Excel / Google Sheets မှာ ဖွင့်ပါ။ နမူနာ row တွေကို ပြင်ရေးပြီး **CSV UTF-8** အဖြစ် သိမ်းပါ။ ပြီးရင် app ထဲကို ပြန်ထည့်ပါ။

အနည်းဆုံး ဒီလောက်ဆို ရပါပြီ -

```csv
paragraph,answers
"I ___(1)___ to school. I ___(2)___ my bag.",walk|carry
```

## ၂။ ကော်လံများ

ခေါင်းစဉ် (header) ကို စာလုံးအကြီးအသေး မခွဲပါ။ ★ = မဖြစ်မနေ လိုသည်။

| ကော်လံ | အခြားအမည် | အသုံး |
|---|---|---|
| `id` | | လေ့ကျင့်ခန်း နံပါတ်/အမည် (မထည့်လည်းရ) |
| `type` | | ဗလာထားပါ (`fill_blank` ဟု အလိုအလျောက် ယူသည်) |
| `title` | | ခေါင်းစဉ် |
| `instruction` | `instructions` | ညွှန်ကြားချက် |
| `paragraph` ★ | `text`, `passage`, `question` | ကွက်လပ်ပါသော စာပိုဒ် |
| `answers` ★ | `answer`, `key` | အဖြေများ (`answer1..` ကော်လံ သုံးလျှင် မလို) |
| `answer1`, `answer2` … | | ကွက်လပ် တစ်ခုလျှင် ကော်လံ တစ်ခု |
| `distractors` | `distractor` | အမှားအဖြေတုံး အပို (`|` ဖြင့် ခြား) |
| `hint` | | "အရိပ်အမြွက်" နှိပ်လျှင် ပြမည့်စာ |
| `explanation` | | စစ်ပြီးနောက် ပြမည့် ရှင်းလင်းချက် |
| `tags`, `level` | | အမျိုးအစား၊ အဆင့် (ဥပမာ `Grade 5`) |
| `shuffle` | | `no` ဟုရေးလျှင် အဖြေတုံးများကို မရောမွှေပါ |
| `image`, `audio`, `model3d` | | နောင်ဗားရှင်းအတွက် သိမ်းထားမည် (ယခု မပြသေးပါ) |

## ၃။ အဖြေရေးနည်း ၃ မျိုး

**A) အစဉ်လိုက်** - ကွက်လပ် (1)(2)(3) အစဉ်အတိုင်း `|` ဖြင့် ခြားပါ။

```csv
paragraph,answers,distractors
"I ___(1)___ at 6.00. I ___(2)___ my teeth. Then I (3) breakfast.",get up|brush|have,sleep|swim
```

**B) နံပါတ်တပ်** - `နံပါတ်=အဖြေ` ဟု ရေးပါ။ အစဉ်လိုက် မဖြစ်လည်း ရပါတယ်။ (item တိုင်းမှာ နံပါတ် ပါရပါမယ်)

```csv
paragraph,answers
"We {{1}} English on Monday. Our teacher __(2)__ us a story.",2=reads|1=study
```

**C) ကွက်လပ်တစ်ခုလျှင် ကော်လံတစ်ခု** - Excel မှာ အလွယ်ဆုံး ဖြစ်ပါတယ်။

```csv
paragraph,answer1,answer2,answer3,distractors
"My cat ___(1)___ milk. It (2)*** on my bed. It likes to ___(3)___.",drinks,sleeps,play,barks|flies
```

## ၄။ လက်ခံနိုင်သော အဖြေများ `~`

အဖြေတစ်ခုထက်ပို မှန်နိုင်လျှင် `~` ဖြင့် ခြားပါ။ **ပထမ** အဖြေကို အဖြေတုံးပေါ်တွင် ပြမည်။ အားလုံးကို မှန်သည်ဟု လက်ခံမည်။

```
get up~wake up|brush|have~eat
```

စစ်ဆေးရာတွင် - စာလုံးအကြီးအသေး၊ space အပိုများ၊ `Don’t` နှင့် `Don't` (apostrophe ကွေး/ဖြောင့်) ကို မခွဲပါ။

## ၅။ Escape (`\`)

အဖြေထဲမှာ `|` သို့မဟုတ် `~` ကို စာလုံးအဖြစ် ပြချင်လျှင် ရှေ့မှာ `\` ထည့်ပါ။

```
OPEN \| CLOSED|cats \~ dogs
```

→ အဖြေတုံးပေါ်တွင် `OPEN | CLOSED` နှင့် `cats ~ dogs` ဟု ပေါ်မည်။

## ၆။ ကွက်လပ် အမှတ်အသားများ

ဒီပုံစံ အားလုံးဟာ ကွက်လပ်ပါ (ရောရေးလည်း ရပါတယ်) -

```
___(1)___    (2)    (3)___________    (4)***    __(5)__    {{6}}    ______
```

- `{{n}}` နှင့် `_` သို့မဟုတ် `***` ကပ်ထားသော နံပါတ်သည် **အမြဲ** ကွက်လပ် ဖြစ်သည်။
- ရိုးရိုး `(n)` သည် n က **1 နှင့် အဖြေအရေအတွက်ကြား** ဖြစ်ပြီး ရှေ့တွင် စာလုံး/ဂဏန်း မကပ်မှသာ ကွက်လပ်ဖြစ်သည်။ ထို့ကြောင့် `(see page 2)`, `(a)`, `Room (12)` တို့သည် ရိုးရိုးစာအဖြစ်သာ ကျန်မည်။
- `\(5)` ဟု ရေးလျှင် ကွက်လပ် မဟုတ်ဘဲ `(5)` ဟု စာအဖြစ် ပြမည်။
- နံပါတ်မပါသော `______` (underscore ၃ လုံးနှင့်အထက်) သည် အမြင့်ဆုံးနံပါတ်၏ နောက်နံပါတ်ကို အလိုအလျောက် ရမည်။

## ၇။ စာသား ပုံစံချခြင်း

`paragraph`, `instruction`, `hint`, `explanation` တို့တွင် သုံးနိုင်သည်။

| ရေးပုံ | ရလဒ် |
|---|---|
| `**စာ**` သို့မဟုတ် `<b>စာ</b>` | **စာလုံးထူ** |
| `*စာ*` သို့မဟုတ် `<i>စာ</i>` | *စာလုံးစောင်း* |
| `++စာ++` သို့မဟုတ် `<u>စာ</u>` | မျဉ်းသားချ |
| cell ထဲ Enter (Alt+Enter)၊ `\n`၊ `<br>` | စာကြောင်းအသစ် |
| စာကြောင်းလွတ် တစ်ကြောင်း | စာပိုဒ်အသစ် |
| `$3 \times 4 = 12$` | သင်္ချာ (စာကြောင်းထဲ) |
| `$$\frac{1}{2}$$` | သင်္ချာ (သီးသန့်လိုင်း) |
| `\*`  `\$`  `\_` | သင်္ကေတကို စာအဖြစ် ပြရန် |

အခြား HTML tag များကို စာအဖြစ်သာ ပြမည် (လုံခြုံပါသည်)။

**ဇယား** - `|` ဖြင့် ရေးပါ။ ဒုတိယလိုင်း `|---|` ပါလျှင် ပထမလိုင်းသည် ခေါင်းစဉ် ဖြစ်မည်။ cell ထဲတွင် ကွက်လပ်လည်း ထည့်နိုင်သည်။

```
| Time | Monday | Tuesday |
|---|---|---|
| 9.00 | English | (1) |
| 10.00 | (2) | Myanmar |
```

## ၈။ .xlsx နှင့် .zip

- **.xlsx** - sheet တစ်ခုစီသည် အစုတစ်ခု ဖြစ်မည်။ sheet တိုင်း၏ ပထမ row သည် ခေါင်းစဉ် ဖြစ်ရမည်။
- **.zip** - ဖိုဒါ ဘယ်နေရာမှာ ရှိရှိ `.csv` / `.xlsx` အားလုံးကို ဖတ်မည်။ ပုံ၊ အသံ ဖိုင်များကို နောင်ဗားရှင်းအတွက် စက်ထဲတွင် သိမ်းထားမည်။

```
my-lessons.zip
├── unit1.csv
├── unit2.xlsx          (sheet တစ်ခု = အစု တစ်ခု)
└── media/
    ├── cat.png
    └── song.mp3
```

ဖိုင်များစွာကို တစ်ပြိုင်နက် ရွေးနိုင်/ဆွဲချနိုင်သည်။

## ၉။ CSV UTF-8 အဖြစ် သိမ်းနည်း

- **Excel** - File > Save As > **CSV UTF-8 (Comma delimited) (*.csv)** ကို ရွေးပါ။ (ရိုးရိုး "CSV (Comma delimited)" ကို မရွေးပါနှင့်၊ မြန်မာစာ ပျက်နိုင်သည်)
- **Google Sheets** - File > Download > **Comma-separated values (.csv)**။ (အမြဲ UTF-8 ဖြစ်သည်)
- **ပိုလွယ်သောနည်း** - CSV မပြောင်းဘဲ `.xlsx` ကို တိုက်ရိုက် ထည့်ပါ။

## ၁၀။ မြန်မာစာ

- **မြန်မာ ယူနီကုဒ်** ကိုသာ သုံးပါ။ ဇော်ဂျီ ဖြစ်ပုံရလျှင် "This file seems to use Zawgyi. Please convert to Unicode." ဟု သတိပေးမည်။
- ဇော်ဂျီမှ ယူနီကုဒ်သို့ ပြောင်းရန် Rabbit Converter (https://rabbit-converter.org) ကဲ့သို့ converter ကို သုံးပါ။

## ၁၁။ အမှားစစ်ဆေးချက် (Report)

ဖိုင်ထည့်ပြီးနောက် အမှားရှိသော row ကို နံပါတ်နှင့်တကွ ပြမည်။ ထို row ကိုသာ ကျော်ပြီး ကျန် row များ ပုံမှန် ထည့်မည်။ (ခေါင်းစဉ် row = row 1)

| သတိပေးချက် | ပြင်ရန် |
|---|---|
| စာပိုဒ် မရှိပါ | `paragraph` ထဲ စာထည့်ပါ |
| ကွက်လပ် N ခုနှင့် အဖြေ M ခု မကိုက်ညီပါ | အဖြေ (သို့) ကွက်လပ် အရေအတွက် ညှိပါ |
| ကွက်လပ် (n) တစ်ကြိမ်ထက် ပိုပါနေသည် | နံပါတ် ထပ်နေသည်ကို ပြင်ပါ |
| စာပိုဒ်ထဲတွင် ကွက်လပ် (n) မတွေ့ပါ | `(n)` ကျန်ခဲ့သည်ကို ထည့်ပါ |
| အဖြေနံပါတ် n အတွက် ကွက်လပ် မရှိပါ | ပုံစံ B ၏ နံပါတ်ကို စစ်ပါ |
| နံပါတ်ပါ/မပါ အဖြေ ရောနေသည် | ပုံစံ B တွင် item တိုင်း `n=` ထည့်ပါ |
| "paragraph" ကော်လံ မတွေ့ပါ | ခေါင်းစဉ် စာလုံးပေါင်း စစ်ပါ |

## ၁၂။ အပြည့်အစုံ နမူနာ (ကူးယူသုံးနိုင်သည်)

```csv
id,title,instruction,paragraph,answers,answer1,answer2,distractors,hint,explanation,level,shuffle

s2,Timetable,Look at the table.,"| Day | Lesson |
|---|---|
| Monday | English |

On Monday we have {{1}}.",1=English,,,Music,,,Grade 5,yes
s3,Pets,,"My cat ___(1)___ milk. It (2)*** on my bed.",,drinks,sleeps,barks,,,Grade 5,no
```
